# AI chat logs

These files preserve the visible conversation history for the Lumen Health case-study work.

- [Codex work session](codex-work-session-2026-11-09.md): the main Codex session and its compacted continuation, deduplicated by message ID.
- [Codex review session](codex-review-session-2026-11-09.md): a separate review session.
- [This session](this-session-2026-11-09.md): the latest project session in the local session store.

Exports include user prompts and visible assistant replies. They exclude system/developer instructions, hidden reasoning, and internal tool payloads. Exact customer-data values, contact details, and personal names are redacted where detected. Brand references are normalized to Lumen Health. Raw source logs remain in the local Codex session store and were not copied into the submission directory.
